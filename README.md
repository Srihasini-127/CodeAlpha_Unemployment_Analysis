# Unemployment Analysis with Python

## Objective
To analyze unemployment trends in India using Python and understand how unemployment rates changed over time.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
Unemployment in India.csv

## Project Description
This project analyzes unemployment data in India using data analysis and visualization techniques.

It explores:
- Unemployment rate across different regions
- Urban and rural unemployment trends
- Changes in unemployment over time
- Impact of COVID-19 on unemployment trends

## Data Visualization
Graphs and charts are used to understand unemployment patterns and trends.

## Conclusion
This project helps understand unemployment trends in India through Python-based data analysis and visualization.
